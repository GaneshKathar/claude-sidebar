Data Flow

1. Hook → State Files

Claude Code starts in a terminal
       │
       │ SessionStart event
       ▼
sidebar-state.sh
       │
       ├──▶ /tmp/claude-sidebar/{session}-{tty}.json
       │     { repo, state: "active", session_id, cwd, tty, timestamp }
       │
       └──▶ /tmp/claude-sidebar/focus{tty}.json  (only at SessionStart)
             { tty, term_program, cmux_workspace_id, cmux_surface_id,
               cmux_socket_path, iterm_session_id, kitty_*, timestamp }

2. State Transitions via Hook Events

Event                →  State written      →  Sidebar shows
─────────────────────────────────────────────────────────────────
SessionStart         →  "active"           →  ● Claude active
UserPromptSubmit     →  "working"          →  ● Claude working
Stop                 →  "idle"             →  ● Claude idle
Notification         →  "alert"            →  ● Needs permission
PermissionRequest    →  "alert"            →  ● Needs permission
PostToolUse          →  (alert→working only)
SessionEnd           →  (deletes state file)

3. Sidebar Reads State

StateReader
  ├── readStates()      → HookStates { byRepo, byTTY, byTTYRepo, byTTYTimestamp }
  └── readFocusFiles()  → [String: TerminalFocus]  (keyed by TTY path)

TerminalDetector
  └── scanProcesses()  → PSScanResult { claudeTTYs, shellPIDs, pidToComm, pidToTTY }
       runs: ps -eo pid,ppid,tty,comm

Polling Cycle

PollingCoordinator
       │
       ├── Darwin notification (com.claudesidebar.update)
       │    └──▶ triggers immediate fast poll
       │
       ├── Fast poll (every 5s when active)
       │    ├── ProcessMonitor.discoverProcesses(ttys:)
       │    ├── ProcessMonitor.detectCWDs(shellPIDs:)
       │    └── Enriches existing windows in-place:
       │         ├── Update Claude state per TTY

       │         ├── Update git branch
       │         └── Detect/watch new processes
       │
       └── Full poll (every pollInterval, default 10s)
            └── TerminalScanner.scan()
                 │
                 ├── Step 1: Adapter enumeration
                 │    Each adapter with .nativeEnumeration:
                 │    ├── ITerm2Adapter  → AppleScript → windows/tabs

                 │

cmux Surface → TTY Mapping

The Problem

cmux's surface.list API returns surface UUIDs but NOT their TTYs. We need TTYs for Claude detection and CWD resolution.

The Solution: sysctl KERN_PROCARGS2

cmux sets env vars in every surface's shell:
  CMUX_SURFACE_ID=112DE1F7-3EA2-4FC9-8DF4-CF73F49383B1
  CMUX_WORKSPACE_ID=761AED64-EA86-4F5C-9759-83096A49B622

macOS restricts reading shell env (login shells → size=32)
BUT child processes inherit env and ARE readable:

  gitstatusd (powerlevel10k — present on every zsh terminal)
  claude     (Claude Code process)
  any command (make, npm, sleep — anything the user runs)

Flow:

  ┌──────────────────────────────────────┐
  │ PSScanResult.pidToTTY              │
  │   pid 43830 → /dev/ttys005           │
  │   pid 61157 → /dev/ttys001           │
  │   (from existing ps scan, free)       │
  └──────────┬───────────────────────────┘
             │
             ▼
  ┌──────────────────────────────────────┐
  │ sysctl(KERN_PROCARGS2, pid)         │
  │   Read env of non-shell processes    │
  │   Find CMUX_SURFACE_ID=xxx           │
  │   ~6 microseconds per PID             │
  │   ~0.05ms total for all TTYs          │
  └──────────┬───────────────────────────┘
             │
             ▼
  ┌──────────────────────────────────────┐
  │ ttyToSurfaceCache (persists across polls)
  │   /dev/ttys001 → E1FD844E-...        │
  │   /dev/ttys002 → 112DE1F7-...        │
  │   /dev/ttys005 → DCCC542A-...        │
  │   (cleaned when shell exits)          │
  └──────────────────────────────────────┘

Incremental: Surfaces without any child process yet
(empty terminal) get mapped on the next poll when the user
runs any command — even a brief ls.

State Sources

Claude tabs:
  Hook state file → "active" / "working" / "idle" / "alert"
  ps scan         → claude process running? (fallback to .idle)

Non-Claude tabs:
  Process running  → .working
  Process error    → .alert
  Process success  → .idle (stays 30s, then clears)
  No activity      → .active (slate — "terminal exists")

Slot header (TerminalWindow.state):
  max(tab.state for all tabs) — highest priority wins

Collapsed bar segments:
  Each segment = one tab's segmentColor
  Claude tabs use claudeState color
  Non-Claude tabs use Theme.active (slate)

Detection: Hook + ps Only (No Title Heuristics)

Claude detection relies on:

  • hookStates.byTTY[tty] — hook state file exists for this TTY
  • psInfo.claudeTTYs.contains(tty) — claude process running on this TTY

Title-based detection was removed to avoid false positives (e.g., "claude-sidebar" directory name matching "claude").

Focus Routing (Tab Click)

User clicks a tab card
       │
       ▼
SidebarController
  scanner.focusSession(windowId: tab.windowId, sessionId: tab.sessionId)
       │
       ▼
TerminalScanner.focusSession()
       │
       ├── Look up focus data:
       │    ├── freshFocus[sessionId] (if sessionId is a TTY path)
       │    └── sessionIdToTab[sessionId].tty (if UUID, find TTY from cache)
       │
       ├── Find adapter:
       │    registry.adapterForTTY(lookupKey, focus, psInfo)
       │    Each adapter's claimsSession() checked in priority order
       │
       ├── Adapter found:  adapter.focusSession(windowId, sessionId, focus)
       │
       ├── Fallback:  Find adapter by tab.terminalType
       │
       └── Last resort:  Activate app by window name/PID

Per-adapter focus:

  CmuxAdapter:
    Case 1: surfaceWorkspaceMap[sessionId] exists
      → activateCmuxApp()
      → workspace.select (bring workspace to front)
      → surface.focus (focus specific pane)

    Case 2: sessionId starts with "/dev/"
      → focus.cmux_workspace_id → workspace.select

    Case 3: workspace UUID fallback
      → workspace.select

  ITerm2Adapter:
    → AppleScript: find session by unique ID, select it

  VSCodeAdapter:
    → Activate VS Code + extension socket → focusByTTY

  GenericAdapter:
    → NSWorkspace activate app by PID
